# Fullbleed 2.2.4 Release Runbook

Status: final

This release publishes compiled content reflow, guarded structural variants, native page-paint
shaders, and the measured 10,365-pages/s hot variable-reflow lane. Release only from the exact
annotated `v2.2.4` tag; registry artifacts are immutable.

## Release Contract

- `Cargo.toml`, `Cargo.lock`, `pyproject.toml`, and CI report `2.2.4`.
- `fullbleed_audit_contract` remains `0.1.3`; the crates workflow reuses the already-published
  audit crate and publishes only a missing main-crate version.
- Wheels retain the `cp310-abi3` tag for CPython 3.10 through 3.14 across all 15 platforms.
- Signed Q32.32 fixed-point layout geometry remains authoritative.
- The public reflow API, exact compact-mode parity, and independent 1,750-page benchmark evidence
  match `ReleaseNotes.MD` and `docs/performance-pass-2026-08-04.md`.

## Clean-Checkout Validation

Run from the proposed release commit in a clean worktree:

```powershell
python tools\check_release_metadata.py --expected-version 2.2.4 --json
python tools\check_license_integrity.py --json
cargo fmt --all --check
cargo test --locked
cargo test --locked --features python,svg_raster
cargo check --locked --all-targets --all-features
python build_backend\fullbleed_build_backend.py wheel --out target\validate-wheel-2.2.4
python -m pip install --force-reinstall target\validate-wheel-2.2.4\*.whl
$env:FULLBLEED_TEST_INSTALLED_NATIVE = "1"
python -m pytest -q
python goldens\run_golden_suite.py --python python verify
python tools\generate_css_parity_status.py --check --json
python tools\check_release_worktree.py --json
```

The compiled-document Stable ABI tests must expose the reflow methods and stats. The independent
benchmark must retain the exact 500/300/150/50 page distribution and all 24,900 markers. Compact
mode must match the frozen ordinary-render SHA-256.

## Packaged Rust and Python Gates

```powershell
rustup run 1.85.0 python tools\smoke_crates_consumer.py --expected-version 2.2.4 --json
cargo publish --locked --dry-run
python build_backend\fullbleed_build_backend.py wheel --out target\release-2.2.4\dist
python build_backend\fullbleed_build_backend.py sdist --out target\release-2.2.4\dist
```

Install and smoke the built wheel, not an editable checkout. Verify the Stable ABI extension,
licenses, specifications, CycloneDX SBOM, wheel tags, and deterministic artifact hashes.

## Publish

1. Commit and push the clean release source.
2. Create and push the annotated tag: `git tag -a v2.2.4 -m "Fullbleed 2.2.4"`.
3. Dispatch `publish-crates.yml` for `v2.2.4` with `publish=true`.
4. Dispatch `release.yml` at `v2.2.4` with `publish_pypi=true`.
5. Create the GitHub release from `ReleaseNotes.MD` and attach all 15 wheels, the source
   distribution, and the SHA-256 manifest produced from the release workflow artifacts.

## Public Verification

```powershell
cargo info fullbleed@2.2.4
python -m pip install --no-cache-dir fullbleed==2.2.4
python -m fullbleed --version
```

Confirm the GitHub release tag resolves to the same commit used by both registry workflows.
