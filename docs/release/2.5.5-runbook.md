# Fullbleed 2.5.5 release runbook

This patch fixes missing gradient fills in finalized PDF previews, including
gradient soft masks and form clipping. Publish from a clean annotated `v2.5.5`
tag after the checks below pass.

## Build and verify

Keep Python, Cargo, the CI smoke version, release defaults, and generated agent
artifacts synchronized at 2.5.5. The audit crate remains 0.1.3 and the optional MCP
adapter remains 0.1.1. Historical example pins retain their verified versions.

Build and install a wheel in an isolated environment. Generate agent artifacts
with `tools/generate_agent_contract.py --python PATH --json`, rebuild and reinstall
the final wheel, and run the generator with `--check`. Build the sdist from the
same final source. Do not hand-edit generated agent files.

- Run the `pdf_raster::shading` Rust regressions and
  `tests/test_fullbleed_gradient_preview.py` against the installed extension.
- Run `python -I tools/smoke_gradient_preview.py --out target/gradient-preview`.
  Retain the 20 cases at 72 and 144 DPI, PDFs, PNGs, probes, and hashes. Require the
  same check to fail on public 2.5.4, where the ordinary linear gradient is blank.
- Compare those actual PDF files with an independent renderer. Retain renderer
  name/version, images, probe coordinates, errors, and source hashes. Include
  off-center radial cones, equal/decreasing radii, and sheared axial gradients.
  These fixture checks do not establish general renderer parity.
- Compare the fixture PDFs with public 2.5.4 output. Inspect the original report
  that exposed the blank chart bars using both native and independent previews.
- Run the full Rust and Python suites, with `FULLBLEED_TEST_INSTALLED_NATIVE=1`
  for Python. Require Linux and Windows CI, including retained gradient evidence.
- Run installed-package smoke, generated-contract checks, deterministic goldens,
  CSS status, license integrity, release metadata, and the bundled Skill validator.
- Require the full release workflow's platform-wheel, source-distribution,
  installed-package, Rust, and existing print-profile checks.

Regressions cover clipped and transformed axial gradients, hard and narrow color
bands, function arrays/exponents/encode mappings, radial geometry, form resource
inheritance and boundaries, path/color preservation, gradient alpha/luminosity
masks, partial graphics-state updates, mask coordinate capture, and cyclic input.
Function/reference depth and gradient size limits prevent unbounded evaluation.

## Supported subset and publishing

The finalized reader supports Type 2/3 exponential/stitching gradient functions,
axial extension flags, radial shadings extended at both ends, and the bounded
Type 1/4 radial-band program emitted by Fullbleed. Gradient masks support Alpha
and DeviceGray/RGB/CMYK-derived Luminosity with identity transfer. This does not
add a general calculator/mesh renderer or universal PDF transparency support.
Unsupported shading programs return errors rather than disappearing silently.

Publish through the configured PyPI trusted publisher and crates.io workflow.
Retain the exact source tag, successful CI evidence, registry metadata, and hashes.
Verify public distributions against release artifacts, install the public wheel
into a fresh environment, and rerun the gradient smoke before claiming availability.

Affected native PNG hashes change. PDF preservation claims cover retained fixtures.
The optional dedicated PDF/VT validator remains unconfigured; its skipped check
does not establish independent conformance.
