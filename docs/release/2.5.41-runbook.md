# Stable 2.5.41: authored preformatted wrapping

Release tag: `v2.5.41`, following stable 2.5.40.

This patch changes the HTML `pre` handler to use computed whitespace and
no-wrap policy for normalization and paragraph layout. The default remains
preformatted, unwrapped text. No public API, dependency or component status
changes. The same source correction is submitted separately to development.

## Required evidence

1. Retain stable 2.5.40 failures: three of four focused native tests fail;
   24 of 31 installed-wheel cases fail, with seven passing controls. Keep
   the original PDFs, PDFium previews, glyph bounds, logs and JUnit reports.
2. Verify the fix using direct, compiled and reflow output, long unbroken

   controls intentionally overflow and must remain unwrapped.
3. Render the unchanged synthetic document-evaluation fixtures, including

4. Build and install the candidate wheel, generate contracts from it, then
   build and install the final wheel and sdist. Keep release versions in
   sync. Run focused and full native/Python tests, installed-package smoke,
   generated-contract checks, package description, license and Skill checks.
5. Require exact-source Windows/Linux CI and retained PDF regression assets.
   Compare the existing pinned CSS corpus without changing its references

6. Publish through existing workflows. Verify registry hashes, release
