# 2.6.0a3: component authoring with corrected inset shadows

Release tag: `v2.6.0a3`. Python version: `2.6.0a3`.
Cargo source version: `2.6.0-alpha.3`.

This candidate merges the qualified stable 2.5.28 inset-shadow corrections into
the component alpha. It preserves the experimental authoring API, static
Bootstrap 5.0.0 components, owned styles, named parts and styled/unstyled HTML
exports. PDF and HTML remain static; neither includes Bootstrap JavaScript.
Previously published alpha and preview artifacts keep their original bytes.

Follow every package, authoring, typing, editor, clean-release and public-registry
gate in the [initial alpha runbook](2.6.0a1-runbook.md), substituting these
versions. Generate agent artifacts from the built and installed candidate,
then rebuild and install the final wheel before checking them. This is a Python
prerelease, with no Rust alpha publication or JavaScript/.NET pin changes.

Additional qualification for this update:

1. Verify preservation of the alpha-only native changes when merging stable
   2.5.28. Run native tests, focused authoring/export tests and the full Python
   suite against the installed final wheel. Retain all existing recipes,
   part-forwarding controls, themes, migration and Bootstrap catalog evidence.
2. Run `tools/smoke_inset_shadows.py --pdfium` for all 27 native fixtures and
   16 clear-region checks at 300 DPI. Compare PDF and preview outputs with the
   qualified stable 2.5.28 outputs; investigate any differences.
3. Run `tools/smoke_component_inset_shadows.py` for eight authored Bootstrap
   cards. The 52 checks exercise reusable defaults, root styles, literal class
   selectors and named body parts, including negative spread, translated holes,
   blur, page-start clipping and zero-area shadows. Retain direct and styled
   export PDFs, host-styled unstyled exports, native/finalized/independent
   previews and 12 complete clear-region comparisons at 300 DPI. Verify repeated
   rendering, source immutability and styled-export PDF byte equality. Run the
   published alpha 2 as a negative control, and render its exported HTML with
   stable 2.5.28 to check the fixture expectations independently of this merge.
4. Preserve the [alpha 2 SVG checks](2.6.0a2-runbook.md), including component
   styling and the 54 SVG fixtures with 810 checks.
5. Run the independent CSS corpus for the final alpha source. Compare against
   both alpha 2 and stable 2.5.28. The stable source retains 1,620 PASS, 24 FAIL
   and 18 REFERENCE-DISPUTED cases and a **failed** workflow conclusion. Keep
   the clipping interaction, increased rounded-blur reference mismatch and
   independent straight-edge blur evidence described in the
   [stable runbook](2.5.28-runbook.md). The alpha's existing oversized-table
   behavior also differs from stable; review the alpha's actual results rather
   than assuming identical corpus output.
6. Qualify the exact committed source through CI and the full release pipeline
   for all 15 wheels and the sdist. Verify public downloads and a fresh installed
   alpha, rerun component examples, and confirm normal pip resolution still
   chooses stable 2.5.28 or a subsequently verified stable release. Mark the
   GitHub release as a prerelease, without replacing the latest stable release.
7. Update the public alpha guide and kit only after verified publication.
   Preserve alpha 1, alpha 2 and earlier preview downloads for reproducibility.

Component coverage and regression fixtures do not establish complete Bootstrap,
browser, accessibility or CSS parity. The dedicated PDF/VT validator remains
unconfigured; profile preflight is not a substitute. Stable API promotion,
independent author feedback and equivalent APIs in other languages remain
separate work. This runbook records required gates, not a publication claim.
