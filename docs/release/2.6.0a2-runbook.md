# 2.6.0a2: component authoring with document-styled inline SVG

Release tag: `v2.6.0a2`. Python version: `2.6.0a2`.
Cargo source version: `2.6.0-alpha.2`.

This candidate merges the qualified stable 2.5.27 SVG fixes into the component
alpha. It preserves the experimental authoring API, static Bootstrap 5.0.0
components, owned styles, named parts, and styled/unstyled HTML exports.
JavaScript is not added to PDF or HTML exports. Existing 2.6.0a1 and earlier
preview artifacts remain pinned to their original source and package bytes.

Follow every package, authoring, typing, editor, clean-release and public-registry
gate in the [initial alpha runbook](2.6.0a1-runbook.md), substituting the versions
above. Generate the contract, CLI schema and `llms.txt` from the built and
installed candidate, then rebuild and install the final wheel before checking
them. This is a Python prerelease; it does not publish a Rust alpha or move the
JavaScript/.NET package pins.

Additional qualification for this update:

1. Verify the merged native source and the experimental component code together.
   Run the focused authoring/export tests, native tests and full installed-wheel
   Python suite. Retain the component recipes, parts, themes, migration controls
   and Bootstrap report/catalog output from that wheel.
2. Run `tools/smoke_svg_styles.py` against the final wheel. Retain all 54 fixtures,
   810 checks, PDF files and native/independent previews. Compare against the
   qualified stable 2.5.27 outputs and investigate differences.
3. Run the independent CSS corpus for the final alpha source. Compare its
   verdicts and scores with both alpha 1 and the qualified stable SVG source.
   The stable source retains 1,619 PASS, 25 FAIL and 18 REFERENCE-DISPUTED cases,
   with the reviewed 710-pixel translucent-rectangle perimeter change described
   in the [2.5.27 runbook](2.5.27-runbook.md). Do not silently treat its failures
   or increased mismatch as a passing comparator.
4. Use the exact committed source and full release pipeline for all 15 wheels
   and the sdist. Verify public downloads and a fresh installed alpha, rerun the
   component examples, and confirm ordinary pip resolution still selects the
   current stable release. Mark the GitHub release as a prerelease.
5. Update the public alpha guide and kit only after publication is verified.
   Preserve the old alpha and preview downloads for reproducibility.

Component coverage and these regression fixtures do not establish complete
Bootstrap, browser, accessibility or CSS/SVG parity. The dedicated PDF/VT
validator remains unconfigured; profile preflight does not replace it. Promotion
of the experimental API and equivalent APIs in other languages remain separate
work.
