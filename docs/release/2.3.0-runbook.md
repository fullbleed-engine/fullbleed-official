# Fullbleed 2.3.0 release runbook

Status: release

This release adds runtime-owned agent discovery, the first-party Agent Skill, the separate `fullbleed-mcp 0.1.0` adapter, generated agent documentation, project `AGENTS.md`, structured action hints, agent workflow examples, the cold-agent acceptance harness, and AgentDocBench infrastructure. Release only from the exact annotated `v2.3.0` tag.

## Release contract

- `Cargo.toml`, `Cargo.lock`, `pyproject.toml`, CI, README installation examples, and release documents report `2.3.0`.
- `fullbleed_audit_contract` remains `0.1.3`.
- `fullbleed-mcp` is independently versioned at `0.1.0` and requires `fullbleed>=2.3.0,<3`.
- Core installation remains self-contained and gains no third-party Python, browser, system-PDF, system-font, or AI-vendor dependency.
- Signed Q32.32 fixed-point geometry, exact font subsetting, deterministic output, and existing compiled fixed/reflow behavior remain authoritative.
- `fullbleed-agent-contract.json`, `cli_schema.md`, and `llms.txt` must be generated from the final installed wheel, never from an editable checkout.
- The Agent Skill stays versionless and points agents to runtime discovery.

## Source and installed-wheel validation

```powershell
python tools\check_release_metadata.py --expected-version 2.3.0 --json
python tools\check_license_integrity.py --json
cargo fmt --all --check
cargo test --locked
cargo test --locked --features python,svg_raster
cargo check --locked --all-targets --all-features

python build_backend\fullbleed_build_backend.py wheel --out target\release-2.3.0\dist
python build_backend\fullbleed_build_backend.py sdist --out target\release-2.3.0\dist
python -m pip install --force-reinstall target\release-2.3.0\dist\fullbleed-2.3.0-*.whl

python tools\smoke_installed_package.py --expected-version 2.3.0 --json
python tools\generate_agent_contract.py --python python --check --json
python tools\generate_mcp_server_json.py --check --json
$env:FULLBLEED_TEST_INSTALLED_NATIVE = "1"
python -m pytest -q
python examples\agent_workflows\run_examples.py --out target\agent-examples-2.3.0 --json
python tools\agentdocbench.py prepare --workspace target\agentdocbench-2.3.0 --task invoice --json
$env:FULLBLEED_TEST_INSTALLED_NATIVE = "1"
python goldens\run_golden_suite.py --python python verify
python tools\generate_css_parity_status.py --check --json
python tools\check_release_worktree.py --json
```

Run the Agent Skill validator from the maintained skill-creation toolchain. Confirm that `SKILL.md` contains no release number and that wheel export preserves all references and optional client metadata.

## MCP package gates

Run after the public core 2.3.0 wheel is available, or in an environment containing the exact validated local core wheel:

```powershell
python -m build packages\fullbleed-mcp --outdir target\release-2.3.0\mcp-dist
python -m twine check target\release-2.3.0\mcp-dist\*
python -m pip install --force-reinstall --no-deps target\release-2.3.0\mcp-dist\fullbleed_mcp-0.1.0-*.whl
python tools\smoke_mcp_stdio.py --json
```

Validate `packages/fullbleed-mcp/server.json` against its declared official schema. Confirm that the built PyPI long description includes exactly `mcp-name: io.github.fullbleed-engine/fullbleed-mcp` before Registry publication.

## Publish order

1. Commit and push the clean release source.
2. Create and push annotated tag `v2.3.0`.
3. Dispatch `publish-crates.yml` for `v2.3.0` with `publish=true`.
4. Dispatch `release.yml` at `v2.3.0` with `publish_pypi=true`.
5. Create the GitHub 2.3.0 release from `ReleaseNotes.MD`; attach all 15 wheels, the source distribution, and SHA-256 manifest.
6. Verify the public core package before publishing `fullbleed-mcp 0.1.0` to PyPI.
7. Dispatch `publish-mcp.yml` for `v2.3.0`; publish the PyPI adapter, then its immutable preview MCP Registry metadata.
8. Validate and publish the repository Agent Skill with the current GitHub CLI preview flow.
9. Update the GitHub description/topics and record public registry URLs.
