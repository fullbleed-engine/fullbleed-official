# Stable v2.5.44: compiled reflow on single-threaded WASIp1

This patch carries the core correction in PR #146 onto stable 2.5.43. It runs
one-worker reflow on the calling thread, clamps unavailable WASIp1 thread
requests, and observes cancellation during the final buffered output write.

## Required evidence

1. Retain the published 2.5.43 Unsupported-thread negative control from issue
   #145, together with the successful native and fixed-layout controls.
2. Build and install the stable candidate; generate agent artifacts from that
   installed runtime, then build and install the final wheel and sdist. Check
   generated contracts, release metadata, package descriptions, installed
   behavior, licensing and the bundled Skill. Preserve focused and full native
   and Python results, including serial and parallel execution.
3. Execute the public-API compiled fixture natively with one and four threads
   and on WASIp1 with an eight-thread override. Retain exact PDF/PNG comparisons,
   replay and rebound glyph checks, malformed-input rejection, cancellation and
   recovery. Inspect extracted text and all distinct pages in an independent
   reader. Exercise the Node package's WASI shim as well as Node's built-in host.
4. Require final-source Windows/Linux CI and the compiled-reflow-wasi artifact.
   Compare all 1,662 unchanged corpus fixtures against stable 2.5.43 with the same
   references and thresholds. Retain every failure and disputed reference;
   investigate any changed raster, verdict or PDF bytes.
5. Publish through the existing workflows after qualification. Verify public
   distribution hashes and fresh Python/Rust consumers before calling the
   release shipped. Retain the source and output evidence with the release.

## Scope and limitations

Stable 2.5.43 has 1,624 PASS, 20 FAIL and 18 disputed corpus references. The
all-pass gate is not green. Development-branch results use a different baseline
and cannot substitute for this comparison. Dedicated PDF/VT validation remains
unavailable. These checks establish the recorded regression behavior, not
general CSS parity, PDF conformance, accessibility or throughput.

The Node API is unchanged; Node 0.8.7 does not expose compiled VDP. A future
binding needs its own lifetime, glyph-reporting, cancellation and resource-limit
checks. Component authoring remains alpha. Evidence is retained under
`target/growth/radial-endpoint-20261029/compiled-reflow-fix/`; final stable
qualification belongs in its `release-2544/` subdirectory.
