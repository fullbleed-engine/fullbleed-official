# Fullbleed 2.5.7 release runbook

This patch compacts embedded TrueType metadata without renumbering retained
glyphs. Publish from a clean annotated `v2.5.7` tag after the checks below pass.

## Build and verify

Keep Cargo, Python, CI smoke metadata, release defaults, and generated agent
artifacts synchronized at 2.5.7. The optional MCP adapter stays at 0.1.1 and the
audit crate stays at 0.1.3. Historical example pins and measured comparisons keep
the versions they actually verified.

Build and install a wheel in an isolated environment. Generate agent artifacts
using `tools/generate_agent_contract.py --python PATH --json`, rebuild and install
the final wheel, then run the generator with `--check`. Build the sdist from that
same source. Do not hand-edit generated agent artifacts.

- Run the focused font-subset Rust tests, then the full Rust suite with default
  and Python/SVG features and the packaged-crate MSRV check.
- Run focused installed-native font, text, preview, compiled-table and profile
  Python tests, followed by the full suite with `FULLBLEED_TEST_INSTALLED_NATIVE=1`.
- Install test-only `pypdf==6.19.0`, `pypdfium2==5.14.0`, `fonttools==4.65.0`, and
  `pillow==12.3.0`. Run `python -I tools/smoke_font_subsets.py --out TARGET`.
  Retain all PDFs, source HTML/CSS, independent and native previews, table sizes,
  versions and hashes. The check independently closes composite dependencies
  and verifies glyph IDs, raw outlines/instructions, metrics, cmap mappings,
  font notices, SFNT checksums and recalculated horizontal-header extrema.
- Record a public 2.5.6 baseline with `--allow-legacy-metadata`. Compare the
  candidate using `--baseline BASELINE_DIRECTORY`. Identical inputs must retain
  text, page count, PDFium pixels and native previews while reducing PDF bytes.
  Running the normal check on 2.5.6 must reject its untrimmed metadata.
- Run the existing styled-text, gradient, template, compiled-binding and
  reproducibility checks. Compare the three golden PDFs with public 2.5.6 using
  an independent renderer before accepting changed PDF hashes; direct PNG
  baselines must stay unchanged.
- Inspect representative invoice, ledger, multilingual, math, symbol and
  non-BMP previews. The unshaped-text case exercises the exposed option too.
- Require Linux/Windows CI and print-profile gates. Retain raw external
  validator reports. The optional dedicated PDF/VT validator remains
  unconfigured; its skipped job is not independent conformance evidence.
- Run installed-package smoke, agent-contract checks, release metadata/license
  checks, deterministic goldens, CSS status and bundled Skill validation.

## Publish and verify

Use the configured PyPI trusted publisher and crates.io workflow after the
final release gates pass. Retain the source tag, workflow conclusions and
artifact hashes. Install the public wheel in a fresh environment and repeat
the font-subset check before promoting the release. Optional bindings remain
independently versioned and require their own installed-package checks when
updating their pinned engine.

The earlier three-renderer comparison stays an immutable 2.5.6 measurement.
Size changes from this patch belong in a separately identified before/after
record; they must not replace its historical PDF artifacts or timing samples.
These checks do not establish general renderer parity, accessibility, print
device compatibility, or throughput.

The table handling follows the OpenType specifications for
[`cmap`](https://learn.microsoft.com/en-us/typography/opentype/spec/cmap),
[`post`](https://learn.microsoft.com/en-us/typography/opentype/spec/post),
[`hmtx`](https://learn.microsoft.com/en-us/typography/opentype/spec/hmtx), and
[`hhea`](https://learn.microsoft.com/en-us/typography/opentype/spec/hhea).
