# Fullbleed 2.2.5 Release Runbook

Status: final

This patch release hardens compiled content reflow, named running strings, fragmentation, and the
Python discovery surface. It also replaces process-global compiled-flow compression selection with
an explicit per-render policy. Release only from the exact annotated `v2.2.5` tag; registry
artifacts are immutable.

## Release Contract

- `Cargo.toml`, `Cargo.lock`, `pyproject.toml`, and CI report `2.2.5`.
- `fullbleed_audit_contract` remains `0.1.3`; the crates workflow reuses the already-published
  audit crate and publishes only the missing main-crate version.
- Wheels retain the `cp310-abi3` tag for CPython 3.10 through 3.14 across all 15 platforms.
- Signed Q32.32 fixed-point layout geometry remains authoritative.
- The stable Python ABI exposes compiled reflow, job-local throughput/compact compression, feature
  discovery, compiled stats, and the corrected fragmentation/named-string behavior.
- Performance language preserves the independently measured 2.2.4 baseline and does not promote a
  best sample to median performance.

## Clean-Checkout Validation

Run from the proposed release commit in a clean worktree:

```powershell
python tools\check_release_metadata.py --expected-version 2.2.5 --json
python tools\check_license_integrity.py --json
cargo fmt --all --check
cargo test --locked
cargo test --locked --features python,svg_raster
cargo check --locked --all-targets --all-features
python build_backend\fullbleed_build_backend.py wheel --out target\validate-wheel-2.2.5
python -m pip install --force-reinstall target\validate-wheel-2.2.5\*.whl
$env:FULLBLEED_TEST_INSTALLED_NATIVE = "1"
python -m pytest -q
python goldens\run_golden_suite.py --python python verify
python tools\generate_css_parity_status.py --check --json
python tools\check_release_worktree.py --json
```

The independent QA probes must show the table and oversized avoid content starting on page 1 and
the named string on every continuation page. Both compression policies must be deterministic and
must remain isolated between calls.

## Packaged Rust and Python Gates

```powershell
rustup run 1.85.0 python tools\smoke_crates_consumer.py --expected-version 2.2.5 --json
cargo publish --locked --dry-run
python build_backend\fullbleed_build_backend.py wheel --out target\release-2.2.5\dist
python build_backend\fullbleed_build_backend.py sdist --out target\release-2.2.5\dist
```

Install and smoke the built wheel, not an editable checkout. Verify the Stable ABI extension,
licenses, specifications, CycloneDX SBOM, wheel tags, and deterministic artifact hashes.

## Publish

1. Commit and push the clean release source.
2. Create and push the annotated tag: `git tag -a v2.2.5 -m "Fullbleed 2.2.5"`.
3. Dispatch `publish-crates.yml` for `v2.2.5` with `publish=true`.
4. Dispatch `release.yml` at `v2.2.5` with `publish_pypi=true`.
5. Create the GitHub release from `ReleaseNotes.MD` and attach all 15 wheels, the source
   distribution, and the SHA-256 manifest produced from the release workflow artifacts.

## Public Verification

```powershell
cargo info fullbleed@2.2.5
python -m pip install --no-cache-dir fullbleed==2.2.5
python -m fullbleed --version
```

Confirm the GitHub release tag resolves to the same commit used by both registry workflows.
