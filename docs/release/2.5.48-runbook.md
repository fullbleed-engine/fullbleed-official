# Stable v2.5.48: page-margin font aliases

## Scope

Page-margin text retains the root's computed family provenance until the
`@page` and margin-box overrides have been applied. The existing font-face
matcher then resolves registered sources, requested weights, Unicode ranges
and size adjustment. Page-family parsing preserves fallback lists and quoted
generic names, decodes CSS escapes and rejects malformed lists.

The change covers text drawn by page-margin boxes. It does not add page-rule
properties or change the registration model: `local()` and supplied URL aliases
refer to fonts registered with Fullbleed. It does not promote component alpha.

## Required qualification

- Keep the public Python 2.5.47 and Node 0.9.0/core 2.5.46 reproductions: body
  text uses the registered face, but a footer using its CSS alias falls back
  to Helvetica. Keep the successful explicit-family control.
- Require all four resolver/parser unit tests, including inherited weight,
  quoted fallback aliases, Unicode ranges, escaped names and invalid lists.
- Run `tools/smoke_page_margin_fonts.py` against the installed candidate on
  Windows and Linux. Its 32 alias/control pairs cover local and URL sources,
  inherited weights, fallback lists, page inheritance, quoted generic aliases,
  size adjustment and named/first pages across ordinary, fixed and reflow PDFs.
- Retain all 126 pages, source inputs and bindings. Compare extracted text,
  embedded font identities and sizes, native previews and independent PDFium
  pixels. Check non-whitespace glyph bounds and prevent unembedded fallback.
- Run the existing page-furniture, running-reflow, font and full Python tests;
  retain skips accurately. Preserve header/footer artifact classification.
- Build and install the final 2.5.48 wheel in CI, then generate agent artifacts
  from that installed runtime. Do not hand-edit the generated artifacts.
- Require final source CI and release gates. Verify release metadata, licenses,
  package contents, the bundled Skill and installed-package behavior.
- Publish through existing trusted workflows only after qualification. Verify
  the public distributions and rerun the installed margin-font check from a
  fresh registry installation before claiming public delivery.

The first source candidate exposed the pre-existing page-family parser's
rejection of comma-separated fallback lists. That candidate is not a release.
These focused checks do not establish general CSS or PDF conformance.
