# Fullbleed 2.5.8 release runbook

This patch fixes normal-family selection when italic faces are registered first.
Publish from a clean annotated `v2.5.8` tag after these checks pass.

1. Synchronize Cargo, Python, CI, release defaults, and generated agent artifacts.
   Keep historical example pins and comparisons at their verified versions.
   Build and install a wheel; regenerate agent artifacts with
   `tools/generate_agent_contract.py --python PATH --json`; rebuild and install
   the final wheel, then run the generator with `--check`.
2. Run focused font-registry Rust tests, full default and Python/SVG Rust suites,
   and the packaged-crate MSRV check. Run focused installed-native font/text
   Python tests, followed by the full suite with
   `FULLBLEED_TEST_INSTALLED_NATIVE=1`.
3. Install development-only `pypdf==6.19.0`, `pypdfium2==5.14.0`,
   `fonttools==4.65.0`, and `pillow==12.3.0`. Run
   `python -I tools/smoke_font_families.py --out TARGET`. Require all 54 cases and
   84 pages: explicit-face controls, both registration orders, file/bundle/
   directory sources, fixed and reflow templates, CSS mappings, and duplicate
   source aliases. Native and independent previews must match the explicit-face
   controls. Inspect representative regular and italic previews.
4. Retain the public 2.5.7 negative control. The same check must reject
   `files-italic-first-normal-pdf` because it embeds `DMSerifDisplay-Italic`.
   Keep all raw PDFs, previews, reports, source hashes, and font licenses.
5. Run existing subset, styled-text, preview, reproducibility, golden, and
   print-profile gates. Require Linux/Windows CI. Keep dedicated PDF/VT
   validation explicitly unverified when that optional validator is unavailable.
6. Publish validated wheels/sdist and the packaged crate through the existing
   trusted workflows. Verify public hashes and fresh installed consumers, then
   retain GitHub release assets and workflow results.

Node and .NET bindings have independent versions and release gates. This core
release does not update those packages or historical downloadable starters.
Do not claim unchanged appearance for documents affected by the selection fix,
complete CSS matching conformance, or a resolved Node crash report.
