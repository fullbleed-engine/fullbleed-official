# Stable 2.5.37: portable package descriptions

Release tag: `v2.5.37`. This patch follows stable 2.5.36 and changes release
tooling, descriptions and version metadata. Keep evidence under
`target/growth/package-entrypoints-20261026/` in the main checkout.

## Release gates

1. Retain the public 2.5.36 package metadata as a negative control. Render the
   actual wheel and sdist descriptions and retain the relative destinations.
2. Exercise the checker with real Markdown rendering, Unicode, inline/fenced
   code, reference links, raw HTML images, anchors, and conflicting metadata.
3. Build and install the 2.5.37 wheel, regenerate all agent artifacts from
   that installed runtime, then build the final wheel and sdist and reinstall
   the final wheel.
4. Check rendered descriptions from both artifacts, install/API/CLI smoke,
   focused and full Python tests, release metadata, license integrity, and the
   bundled Skill. Inspect the rendered package description and follow its
   primary links. Keep runtime/build dependencies unchanged.
5. Require exact-source Windows/Linux CI, including the new package-description
   gate. Verify that Rust engine, Python API and bundled assets are unchanged
   from 2.5.36; compare representative PDFs and previews from public 2.5.36 and
   the candidate. Preserve existing corpus failures and evidence.
6. Publish through the existing release workflows only after their gates pass.
   Validate descriptions from all 15 wheels and the sdist before the PyPI upload.
   Verify registry metadata/checksums and fresh public Python and Rust consumers.

This documentation and packaging patch does not claim a new full CSS corpus
result or broader rendering compatibility. Python 3.15 coverage stays within
the retained compatibility evidence; the release does not change its support
policy or infer new interpreter support from a metadata edit.
