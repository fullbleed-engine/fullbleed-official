# 2.5.26: embedded stylesheets in complete HTML documents

Release tag: `v2.5.26`.

Supported static `<style>` sheets now participate in the native document cascade.
The same prepared HTML/CSS context serves direct rendering, compilation, fixed
and reflow bindings, previews, reporting and sequential/parallel batches. Bundle
assets precede embedded sheets; the explicit CSS argument follows them. Each
source keeps a separate parsing boundary. Embedded page settings initialize
streaming writers from the first record, within the existing single-paper-size
batch contract.

The [guide](../embedded-stylesheets.md) documents print-media and preferred-set
selection, raw HTML text versus SVG foreign parsing, compiled-style ownership,
diagnostics, explicit assets and the remaining SVG cascade boundary. The
experimental component redesign in PR #85 is separate from this release.

## Verification and publishing

1. Build and install the release wheel, generate the agent artifacts from that
   installed runtime, then rebuild and reinstall the final packaged artifacts.
   Check the generated contracts, release metadata and bundled Skill.
2. Run focused embedded-stylesheet tests and the full Python suite with the
   installed extension. Run
   `python -I tools/smoke_embedded_styles.py --out target/embedded-styles` against
   the final installed wheel and retain its 195 output checks, PDFs and images.
   Execute the guide example and inspect its final A5 PDF.
3. Use the clean GitHub release checkout for the release-worktree gate and
   full release pipeline. It validates the source and installed distributions
   before publishing the complete set of 15 platform wheels and one sdist.
   The release workflow retains the new embedded-style output artifacts alongside
   the existing native, profile, font, text, layout and portability evidence.
4. Publish the matching Rust crate through its existing exact-tag workflow.
   Check the public Python wheel and Rust registry version after publication;
   do not infer publication from a tag or a successful build job.
