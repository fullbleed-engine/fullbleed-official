# 2.5.13 tagged structure release

Target release tag: `v2.5.13`.

This releases the engine changes validated for [2.5.12](2.5.12-runbook.md).
The 2.5.12 publishing workflows stopped on an outdated README wheel example
before any registry upload. Preserve that tag and the failed workflow receipts.

1. Run `python tools/check_release_metadata.py --expected-version 2.5.13 --json`.
   The same check must pass in pull-request CI.
2. Confirm the Rust and Python implementation, fixtures and tests are unchanged
   from `v2.5.12`. Build and install the 2.5.13 wheel, regenerate agent artifacts
   from it, and check the final wheel and generated artifacts.
3. Run the 61 tagged decoration/list/figure regressions against the installed
   wheel. Retain the earlier full suites and golden evidence, and require the
   complete CI run and 17-profile gate for the final source commit.
4. Publish via the trusted PyPI and crates.io workflows. Compare every public
   distribution with CI and verify fresh Python and Rust consumers. Validate
   the rich specimens with pinned veraPDF 1.30.2 and retain source, PDFs,
   reports and checksums. The declared machine-check scope and PDF/VT limits
   from the 2.5.12 runbook still apply.
5. Retain release evidence before removing task-owned Cargo build caches.

Dependent SDKs still require their own versioned upgrades and verification.
