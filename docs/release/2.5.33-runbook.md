# Fullbleed v2.5.33 release runbook

Publication requires the checks below to complete with retained evidence.
The GitHub release attaches the completed verification summaries and exact
artifact hashes; this runbook defines the required checks and their limits.

## Scope

Backport the table-caption correction from `48b0e5b` in the component preview
onto stable `a2d2702e7d74160270ed4b41cb1dd07663d7e73b` (2.5.32), resolving
[issue #98](https://github.com/fullbleed-engine/fullbleed-official/issues/98).
The patch keeps each Caption directly inside its owning Table, with paragraph
content, correct top/bottom reading order, and stable ownership across nested
tables, page continuations and multiple records. Empty or hidden captions retain
their visual layout without empty semantic tags.

The stable source has no experimental component flow-gap option. The backport
omits only three patch context lines referring to that option; the caption-fix
code is unchanged. The experimental Python component package is not included.

## Required evidence

- Reproduce the defect with a public 2.5.32 wheel whose installed files match
  the retained PyPI distribution.
- Run the native regression suite and focused Python tests, then the full
  Python suite against the final installed candidate wheel.
- Check all 225 caption cases with independent saved-PDF readers: logical
  ownership, text, reading order, nested tables, hidden/empty captions,
  pagination, compiled rendering, reflow and record isolation.
- Preserve saved-PDF pixels, extracted page text and untagged PDF bytes against
  the stable control. Retain both baseline failures and candidate results.
- Validate final caption PDFs with independent PDF/UA-1 and PDF/UA-2 profiles,
  retaining raw reports, clean stderr and exact PDF hashes.
- Check existing rich-table and oversized-row output so the correction retains
  the previous stable release's pagination and content behavior.
- Build/install a bootstrap wheel, generate the agent artifacts from that
  runtime, rebuild/install the final wheel and verify the generated artifacts.
- Validate package metadata, installed-package behavior, and the bundled Skill.
- Require current-source CI, retain and assess the independent CSS corpus,
  then verify the exact-tag distribution set and public package downloads.

The retained public 2.5.32 control fails the independent structure checks in
all 225 caption cases. Its PDF/UA-2 top-caption and nested-caption controls also
fail veraPDF 1.30.3, while the corresponding PDF/UA-1 top-caption control passes
that validator. This is why both saved-PDF structural checks and independent
profile validation are required.

Machine and fixture checks do not establish human assistive-technology usability
or general accessibility conformance. Dedicated PDF/VT validation remains
unconfigured and is outside this change's evidence.
