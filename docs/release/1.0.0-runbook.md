# Fullbleed 1.0.0 Release Runbook

This runbook is for the final `1.0.0` release commit.

## Preconditions

- The intended release branch is checked out.
- No local-only artifacts are present in the worktree.
- `git status --short` is clean before final artifact builds.
- Python is CPython 3.11 for the Windows smoke path.
- Rust stable is installed.
- `maturin` and `pytest` are installed in the active release environment.

## Clean-Tree Gate

```powershell
python tools\check_release_worktree.py --json
```

Expected: `ok: true`, `counts.total: 0`, and
`counts.tracked_artifact_violations: 0`.

If this fails, do not tag. Commit intended source/docs/tests, stash unrelated
work, or remove generated artifacts deliberately. The gate also rejects tracked
generated artifacts such as `.pytest_cache/`, `*.pyd`, `*.so`, `*.dll`,
`*.dylib`, root `fullbleed_css_fixture_*.jsonl` traces, and
`fullbleed_preflight*` logs even if the worktree is otherwise clean.

## Source Validation

```powershell
cargo fmt --check
cargo test --locked
cargo test --locked --features svg_raster
python -m maturin develop --release --features python,svg_raster
python -m pytest -q
python tools\generate_css_parity_status.py --check --json
python tools\run_css_fixture_suite.py --fixtures inline_svg_image_mixed_run_torture --jobs 1 --json
python -m fullbleed doctor --strict --json
python -m fullbleed compliance --strict --json
python tools\check_license_integrity.py --json
```

Expected:

- Rust and Python tests pass.
- The Python native extension is rebuilt from source with `python,svg_raster`;
  it must remain ignored build output, not tracked source.
- The inline/SVG/image release fixture passes.
- Doctor, compliance, and license integrity return `ok: true`.

## PDF Profile Gate

```powershell
python tools\validate_pdf_profiles.py --out output\conformance_validation_harness --download-verapdf --install-pdf-oxide --strict-external
```

Expected:

- Summary `ok: true`.
- 17 profile specimens generated and replay-hashed deterministically.
- veraPDF passes PDF/A, PDF/UA, and WTPDF profiles.
- `pdf_oxide` passes `pdfx4` and the PDF/X-4 base of `pdfvt1`.
- PDF/VT DPart inspection passes.

PDF/VT certification language is only allowed if a dedicated validator is
configured:

```powershell
python tools\validate_pdf_profiles.py --profile pdfvt1 --pdfvt-cmd "<validator> {pdf}" --require-dedicated-pdfvt
```

## Package Dry-Runs

```powershell
cargo publish --dry-run
cargo publish --dry-run --manifest-path crates\fullbleed_audit_contract\Cargo.toml
```

Expected:

- Main crate packages only the constrained source/package file set.
- The audit contract crate may report that `0.1.0` already exists; do not
  republish it unchanged.

## Wheel Build And Installed-Wheel Smoke

Build with the release feature set:

```powershell
python -m maturin build --release --features python,svg_raster
python -m pip install --force-reinstall target\wheels\fullbleed-*.whl
python -m pytest tests\test_fullbleed_svg_raster_fallback.py -q
python -m fullbleed doctor --strict --json
```

For final publication, repeat equivalent installed-wheel smoke on every wheel
platform claimed by the release. README currently documents Linux and Windows
as smoke-tested release paths and macOS as maintainer-untested.

## Publish Sequence

1. Confirm all gates above passed on the exact release commit.
2. Tag `v1.0.0`.
3. Build final wheels from the tag.
4. Upload crates.io and PyPI artifacts according to project credentials.
5. Install from the published artifact in a clean environment and run:

```powershell
python -m fullbleed --version
python -m fullbleed doctor --strict --json
python -m pytest tests\test_fullbleed_svg_raster_fallback.py -q
```

## Failure Handling

- If source tests fail, fix source or tests before rebuilding artifacts.
- If PDF profile validation fails, do not publish standards claims until the
  harness is green again or the claim is narrowed.
- If wheel smoke fails, discard that wheel and rebuild from the exact fixed
  commit.
- If the worktree becomes dirty during release, restart from the clean-tree
  gate.
