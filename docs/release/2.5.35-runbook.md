# Stable 2.5.35: clipped auto-height pagination

The release tag is `v2.5.35`.

This candidate backports the pagination correction from PR #127 onto stable
2.5.34. The stable splitter retains its existing Option-based API. The component
authoring surface and PR #128's percentage-width allocator are outside this
backport; stable percentage-width behavior must be assessed independently.

## Required evidence

Keep immutable receipts, wheel identities, and rendered fixtures under
`target/growth/rbat-pdf-20261023/stable-pagination/`.

1. Calibrate the saved-PDF regressions against the registry-verified 2.5.34
   wheel. Preserve failures and fixed-viewport controls.
2. Run formatting, focused overflow tests, and the full Rust suite using the
   existing Cargo cache. Preserve the stable splitting and diagnostics APIs.
3. Build and install the candidate wheel, generate contracts from that runtime,
   then rebuild and install the final wheel. Check release metadata, installed
   behavior, dependency boundaries, license, and bundled Skill.
4. Run focused and full Python tests. Check all table-row markers, repeated
   headers, physical glyph bounds, forced page breaks, footnote placement, and
   repeat-render determinism. Inspect a realistic long-report PDF.
5. Run the unchanged golden verifier using isolated copies of tracked fixture
   inputs. Never read or restore user-owned output files.
6. Inspect tagged multi-page output and its structure. Retain exact PDF hashes
   for any automated validator checks; make no arbitrary-document accessibility
   or human usability claim from fixture results.
7. Review exact-source Windows/Linux CI and the pinned independent CSS corpus.
   Compare to the stable predecessor, keeping all existing failures, references,
   and thresholds visible.
8. Publish only after release gates pass. Verify fresh public Python and Rust
   consumers against registry checksums and exact source identity before calling
   the correction published.

Actual results belong in the retained receipts, not assumed counts in this
runbook. A locally installed candidate is not a published stable package.
