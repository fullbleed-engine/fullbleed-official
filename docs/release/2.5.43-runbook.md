# Stable v2.5.43: radial final-stop colors

This backports the correction in PR #143 to stable 2.5.42. A radial gradient
whose final stops coincide must continue its final color outside the ending
shape, as described by CSS Images 3 section 3.4.2. A zero-width final PDF
function interval did not produce that visible result in the reviewed readers.

## Required evidence

1. Retain the valid public 2.5.42 negative control: nine failing endpoint
   cases and three passing controls. Preserve the earlier invalid mixed-wrapper
   baseline as a harness error, not product evidence.
2. Build and install the stable candidate, generate agent artifacts from that
   installed runtime, then build and install the final wheel and sdist. Check
   focused and full Python/native tests, installed-package behavior, generated
   contracts, version metadata, licensing, package descriptions and bundled Skill.
3. Retain direct, compiled and repeated PDFs for all twelve radial cases.
   Inspect final-stop colors in native previews and PDFium at 72, 144 and
   300 DPI, including opacity-only and fully transparent endpoints. Independently
   inspect function domains, circle mappings and original stop colors. Preserve
   the smooth, early-ending and repeating controls; measure any interior changes.
4. Require final-source Windows/Linux CI and its retained twelve PDFs per
   platform. Compare the unchanged 1,662-case corpus against the retained
   stable 2.5.42 baseline, preserving inputs, references and thresholds. Keep
   every failure and disputed reference; inspect every changed raster or verdict.
5. Publish through the existing release workflows only after qualification.
   Verify public distribution hashes and fresh Python/Rust consumers before
   calling the release shipped.

## Scope and limitations

The stable 2.5.42 baseline has 1,624 PASS, 20 FAIL and 18 disputed references.
Its all-pass corpus gate is not green. The development baseline differs and
must not substitute for that stable comparison. The original border-image
comparison failures remain open. The specific radial regression checks do not
establish complete CSS parity, PDF conformance, accessibility or performance.
Dedicated PDF/VT validation remains unavailable. Component authoring remains
alpha; this patch adds no public API or runtime dependency.

Development evidence is retained under
`target/growth/radial-endpoint-20261029/` in the main checkout. The development
corpus predates a two-argument CI output-path correction; retained Git-tree
identity proof covers every other tracked file, and final-head source CI checks
the corrected paths. Stable release evidence belongs in `stable-2543/`.
