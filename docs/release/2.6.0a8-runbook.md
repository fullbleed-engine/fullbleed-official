# Component alpha 8 qualification

Python prerelease: `2.6.0a8`, tag `v2.6.0a8`. Cargo source: `2.6.0-alpha.8`.

This preview publishes the reviewed page-furniture, page-margin sizing and
internal deferred-running-layout changes with the stable 2.5.34 fixes. Keep the
component API experimental. Stable installation must continue to select 2.5.34.

1. Merge the stable source and release workflow into the existing component
   branch without changing unrelated work. Preserve its reviewed native layout
   implementation and add the stable shared-binding regression. Synchronize
   package, Cargo, lockfile and CI metadata.
2. Run the native suite. Build and install the new-version wheel, regenerate
   agent artifacts from that installed runtime, then rebuild and install the
   final wheel. Check contracts, distribution contents, release metadata,
   installed behavior and the bundled Skill.
3. Run focused and full Python tests on the final installed wheel. Retain all
   120 furniture, 195 margin-geometry, 120 deferred-running-layout and 54 ordinary
   running-reflow cases. Verify the exact issue #104 fixture in both compression
   modes. Compare saved outputs with the reviewed candidates, and retain
   independent PDF/UA reports for the actual output. Reuse validation only when
   the saved PDF and its retained successful report have verified hashes.
4. Recreate Northstar and Common Ground from both authoring paths. Recreate the
   accessible guide with PDF/UA-1 and PDF/UA-2. Retain text, pixels, structure,
   repeated-output comparisons and independent validator evidence. Keep old
   source kits and downloads immutable.
5. Require current-source Windows/Linux CI and inspect its saved output.
   Retain the complete independent CSS corpus, including raw failures and
   disputed references. Compare all saved outputs, verdicts and scores against
   the reviewed running-layout candidate. Do not adjust references or tolerances
   to obtain a passing workflow. Corpus triggering includes all native modules
   and package/build inputs so relevant source changes cannot silently skip it.
6. Verify the annotated exact-tag release workflow, all 15 public wheels and the
   source archive. Reproduce the regression matrices and authoring showcases in
   a fresh public installation before publishing the GitHub prerelease or
   closing issue #103. Verify that ordinary pip resolution still selects stable.
7. Attach the final checksums, raw reports and reproducible source to the release.
   Public copy must distinguish the shipped fix from prior private candidates
   that also carried the 2.6.0a7 version string.

The internal running layout checks measured boxes, not complete painted bounds.
Oversized descendants, transforms, shadows and positioned paint can clip.
Streaming rendering is not atomic. Changed bindings reflow running content even
when headers are static. Public PageBand/PageNumbers APIs remain design work.
The existing corpus failures remain visible. Fixture-specific PDF/UA checks do
not establish human assistive-technology usability, general WCAG certification
or conformance for arbitrary documents. Static Bootstrap exports contain no
Bootstrap JavaScript. Dedicated PDF/VT validation remains unconfigured.
