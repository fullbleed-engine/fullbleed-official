# 2.5.30: same-font inline spacing and pagination

Release tag: `v2.5.30`.

A same-font color span, nested span or generated `::before` / `::after` content
could increase a row's logical height at `line-height: 1`. With bundled Noto Sans
at 20px, 24 rows that occupy three pages as plain text became four pages after
adding an accent color. Inter at 12px reproduced the same defect.

Paragraph inline ascent uses the logical baseline without adding ink overflow.
Registered fonts with integral CSS-pixel sizes and unit line height round descent
to the nearest CSS pixel. Positive leading retains its raw phase until painting;
integral mixed-size text encloses the expanded baseline union. Terminal rounding
uses the composed line baseline and is restricted to ordinary text, preserving
atomic inline alignment and raw table/page-margin painting. Fractional used font
sizes retain their prior metric policy. Floated initials resolve their paint
target separately from line geometry. A shadow does not move foreground glyphs.

The remote-template CLI help also directs users to `fullbleed new list`; its
previous example ID was absent from the current registry. This changes help text
only. Generate its parser contract from the installed wheel.
