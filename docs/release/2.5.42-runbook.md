# Stable 2.5.42: gradient stitching boundaries

Release tag: `v2.5.42`, following stable 2.5.41.

This backports the development correction in PR #141 to stable 2.5.41.
PDF Type 3 functions must not contain empty interior subdomains. Hard stops
instead join the adjacent nonempty functions. Equality of the final bound
and the domain endpoint is permitted by ISO 32000-1 section 7.10.4.

4. Require exact-source Windows/Linux CI. Run the existing 1,662-case CSS

5. Publish through existing workflows only after qualification. Verify all

   calling the release shipped.

## Scope and limitations

The reviewed development corpus retains 1,625 PASS, 19 FAIL and 18 disputed
references; the stable baseline has 1,624 PASS, 20 FAIL and 18 disputed
references. Use the stable baseline for this release comparison.

Additional radial endpoint specimens preserve the old rendered pixels, but
do not establish correct visible extension of coincident final-stop colors
outside the radius. That existing limitation is retained separately from
the serialized-function correction. The original border-image comparison
failures also remain unresolved. The evidence does not establish complete
conformance, CSS parity, accessibility, performance or independent adoption.
Dedicated PDF/VT validation remains unavailable. Component authoring stays
alpha; this release adds no public API or runtime dependency.

Evidence is retained in the main checkout under
`target/growth/border-image-review-20261029/`, including `stable-2542/`.
