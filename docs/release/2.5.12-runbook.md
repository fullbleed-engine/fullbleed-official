# 2.5.12 tagged structure release

Target release tag: `v2.5.12`.

In 2.5.11, a styled paragraph with different inline font sizes can create a
grouping tag without an MCID. Borders and backgrounds within that group are
not automatically artifacts, so the resulting PDF can fail PDF/UA validation.
An automatic artifact can also remain open when screen-reader-only ActualText
begins. Lists also lack ListNumbering attributes, and HTML figure captions
are flattened into the document. Preserve failing outputs before checking
these corrections.

1. Run the two focused Rust regressions in `src/pdf.rs`. They cover grouping
   decoration, meaningful figure paint inside a nested group, and an ActualText
   boundary after decorative paint.
2. Build and install a wheel. Run
   `FULLBLEED_TEST_INSTALLED_NATIVE=1 python -m pytest
   tests/test_fullbleed_tagged_decorations.py
   tests/test_fullbleed_list_figure_semantics.py -q` with test-only pypdf 6.19.0.
   These cases inspect actual PDF operators and structure trees across tagged, PDF/UA-1 and
   PDF/UA-2 output, including ordinary, compiled, repeated and reflow rendering.
3. Render the retained styled notice and validate the exact PDF with veraPDF.
   Compare its text, structure, alternative text, table attributes and page
   previews with the failed baseline. Review the visible output and reading
   sequence. A machine-check pass alone is not full accessibility acceptance.
   Also run the richer `tools/fixtures/tagged-structure` specimen with the
   operational profile harness. PDF/UA-1, PDF/UA-2 and both WTPDF profiles
   retain their own independent validator reports and deterministic replay.
4. Run the complete Python and Rust suites, existing goldens, installed-package
   checks and the required 17-profile preflight. Retain validator reports and
   artifact hashes; keep independent PDF/VT validation scope unchanged.
5. Synchronize release versions, generate agent artifacts from the installed
   final-version wheel, rebuild, and check the final artifact. Validate the
   bundled Skill and exact-source CI before merging and tagging.
6. Publish through the existing trusted workflows. Verify public PyPI and
   crates.io artifacts and fresh consumers. Dependent SDKs require their own
   upgrades and evidence before publishing examples that depend on the fix.

Semantic references: [PDF Association structure attributes](https://pdfa.org/download-area/cheat-sheets/StructureAttributes.pdf)
and [Tagged PDF best practices](https://pdfa.org/download-area/publications/Tagged-PDF-Best-Practice-Guide.pdf).
The emitted list names describe actual marker styles. Caption association
follows the source figure boundary; it is not inferred from neighboring prose.
Single-image figures lift the image alternative to the captioned Figure. A
figure containing multiple illustrations or other content remains a semantic
Sect with each illustration's description intact. Missing alternatives remain
missing and must still be fixed in source.
