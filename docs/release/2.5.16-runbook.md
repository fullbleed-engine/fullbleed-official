# 2.5.16 independent font-synthesis release

Target release tag: `v2.5.16`.

1. Preserve the reviewed implementation from [PR #58](https://github.com/fullbleed-engine/fullbleed-official/pull/58).
   Require its Windows/Linux CI and review the complete pinned CSS corpus,
   retaining failures and disputed references. Keep source-candidate and public
   registry-wheel identities distinct; do not change reference inputs or thresholds.
2. Build and install the final-version wheel. Run
   `tools/smoke_font_synthesis.py`, retaining 130 cases / 221 pages, deterministic
   replay, text extraction and native, finalized-PDF and independent PDFium
   controls. Compare final-version previews with the reviewed source build.
3. Regenerate agent artifacts from that installed wheel, rebuild with those
   resources, and check the final installation. Validate release metadata,
   licensing, the bundled Skill, focused tests and the full Python suite.
4. Require normal CI on the exact release-preparation commit, including the
   standard-GIL Python 3.15 rc3 preview jobs and existing print-profile preflight.
   Tag the merged, validated source and publish through the trusted PyPI and
   crates.io workflows. Release CI must retain the final synthesis evidence.
5. Verify registry metadata and checksums and use fresh public Python and Rust
   consumers before reporting the release as available. Publish evidence with
   exact source, package and reader identities.

Small-cap positive controls cover ordinary and compiled reflow output. Synthetic
small caps with fixed binding slots remain unsupported. The finalized-preview
reader can omit the fixed-slot synthetic-bold stroke; independent PDFium must
still distinguish all four actual PDF styles. These known limitations are not
counted as new conformance or preview-parity passes.

The position control affects the existing default footnote fallback, not general
authored `font-variant-position`. No complete CSS Fonts or new standards claim is
made. The optional dedicated PDF/VT validator remains unconfigured. Node and
.NET bindings retain their existing pins until separately upgraded and verified.
