Python prerelease: `2.6.0a10`, tag `v2.6.0a10`. Cargo source: `2.6.0-alpha.10`.

This release packages the decoration continuity and inline-boundary fixes from
[PR #108](https://github.com/fullbleed-engine/fullbleed-official/pull/108), merged
as `d6bf51874ab559edc14bbb5f0bbf7edb28bc04eb`. Preserve that rendering
implementation while preparing the release. Keep the component API experimental
and ordinary stable installation on its separately published version.

1. Confirm current registry versions and the unused release tag. Synchronize
   Python, Cargo, lockfile, CI and release metadata. Preserve unrelated local
   files and record the exact source tree and protected-file hashes.
2. Build and install the new-version wheel. Generate agent artifacts from that
   installed runtime, rebuild and install the final wheel, then check generated
   contracts, package contents, release metadata, installed behavior and the
   bundled Skill. Do not hand-edit generated contracts.
3. Run focused tests and the full Python suite against the final installed
   extension. Verify 80 decoration-space cases across direct, compiled and
   preview paths, together with the 100 thickness cases. Compare saved PDFs and
   pixels with the qualified implementation; preserve the established references

4. Recreate Northstar and Common Ground through both component and HTML/CSS
   authoring paths, the accessible showcase profiles, and representative page-band
   output. Retain text, structure, deterministic PDF bytes and styled/unstyled
   HTML checks. A prior external validator result can be reused only when its
   successful receipt and exact input PDF hash match; otherwise validate the

5. Require exact-source Windows/Linux CI and inspect the retained outputs. Keep

   thresholds. Compare it with the qualified merged implementation: 1,623 pass,
   21 fail and 18 reference-disputed cases. A failing corpus remains a failing

6. Verify the immutable annotated tag, final source commit and release workflow.
   The installed release gate must run the new decoration-space matrix and retain
   its PDF/preview evidence. Check all 15 public wheels and the source archive,

7. Publish the GitHub prerelease and retained evidence only after package

The fix covers the retained solid-decoration fixtures and their shadows. It does
not establish arbitrary CSS decoration-layer composition or browser parity.
Existing component, pagination, streaming and HTML-export limits still apply.
Dedicated PDF/VT validation remains unconfigured.
