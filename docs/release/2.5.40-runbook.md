# Stable 2.5.40: continuous text decorations

Release tag: `v2.5.40`, following stable 2.5.39. This backports development
commit `30b32db83fe882900fdc7c68c60ba884fb44ffdc` and adds the installed-native
regression to stable CI and the release gate. Evidence is retained under the
main checkout's `target/growth/stable-development-delta-20261027/`.

## Required release evidence

1. Retain the installed 2.5.39 negative control: 13 failures and 3 passing
   controls across 16 direct-render cases. Keep the PDFs, independent PDFium
   previews and machine-readable assertions. Do not change tolerances.
2. Build and install the candidate wheel. Generate agent artifacts from that
   runtime, then build and install the final wheel and sdist. Keep Python,
   Cargo, generated-contract, package-description and CI versions synchronized.
3. Run the existing 16-case decoration probe in direct, compiled, fixed-record,
   reflow-record and compact-record modes. Check continuous lines, collapsed
   edges, authored span boundaries, nested text, raised baselines, atomic
   inlines, shadows and unchanged glyph positions. Require deterministic PDF
   bytes and independent PDFium, native and finalized-PDF previews.
4. Visually inspect representative results. Run focused and full native and
   Python tests, the decoration-thickness check, installed-package smoke,
   generated-contract checks, license integrity and bundled Skill validation.
5. Require exact-source Windows/Linux CI. Run the pinned CSS corpus using the
   original inputs, references and thresholds. Compare with the retained
   published 2.5.39 run; preserve failed and disputed outcomes without calling
   its all-pass gate successful when failures remain.
6. Publish using the existing release workflows after qualification. Verify
   registry checksums, release descriptions and fresh public Python/Rust
   consumers. The development branch already contains this correction.

The cases establish a bounded rendering correction. They do not prove general
CSS parity, performance, accessibility or PDF standards conformance. They also
do not qualify the component alpha for stable release.
