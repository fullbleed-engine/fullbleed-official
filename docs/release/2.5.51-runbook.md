# Stable v2.5.51: runnable starters and font-family cascade

## Changes

The invoice and statement starters now include editable JSON and standard-library
templates. Their scripts escape inserted text, calculate decimal amounts, embed
bundled Inter, and emit finalized PDF previews. Running either original starter
previously printed its unexpanded Jinja placeholders and loop instructions.

A winning concrete `font-family` declaration now clears an earlier deferred
`var()` value. A winning variable that cannot resolve inherits the parent's
family rather than reviving an earlier losing rule. This also repairs the
accessible starter's embedded-font failure: its authored Inter family now wins
over Bootstrap's earlier body rule.

`tools/generate_agent_contract.py`. Rebuild the final source, verify packaged
resources, installed starter execution, release metadata, licenses, and the
bundled Skill, and retain all final CI conclusions. Publish through trusted
workflows and verify fresh public distributions before claiming delivery.

Carry the starter changes and the missing inherited-fallback fix into main;
main already contains the concrete-winner correction. Merge only after its own
CI passes. Documentation should execute the generated starters rather than
checking only that their scripts exist.

These checks do not establish independent PDF/UA certification, complete CSS
conformance, performance improvement, or independent production adoption.
Component authoring retains its existing alpha status.
