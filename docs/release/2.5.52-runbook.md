# Stable v2.5.52: reported grid, font, and invoice fixes

## Changes

This patch backports [#161](https://github.com/fullbleed-engine/fullbleed-official/pull/161)
and the runtime fixes from [#162](https://github.com/fullbleed-engine/fullbleed-official/pull/162)
onto 2.5.51. The grid commit retains the contributor's authorship. The release
does not include the unrelated 2.6 alpha changes on master.

- Spanning grid items use the sum of their resolved tracks and intervening gaps.
- Registered static font families select numeric CSS weights using fallback order.
- CFF OpenType fonts retain their outline scale; native finalized-PDF previews
  follow character-to-CID-to-glyph mappings and the associated advances.
- Block `strong` and `b` elements receive their expected default bold weight.
- Wrapped table cells retain inherited alignment. Standard 14 font layout uses
  painted glyph advances, including the writer's character substitutions.
- Hard-hyphen wrap opportunities keep invoice amount columns within the page.

Alignment and font measurement also require focused backports from `8704ac8`
and `e7ae956`, which were already present in the reviewed main candidate.
Built-in-font line breaks can change because estimated character widths are
replaced with the actual advances. Registered font measurement is unchanged.

Native variable-font axis instancing remains unsupported. The font guide gives
a verified FontTools static-instance workaround. Component authoring retains
its existing alpha status.

## Existing review evidence

The [merged main candidate CI](https://github.com/fullbleed-engine/fullbleed-official/actions/runs/42413557067)
passed. Its installed Windows wheel passed 214 focused and adjacent tests. The
new checks cover direct and compiled rendering, unequal grid tracks, static
font-weight ordering, CFF outline size, native preview bounds, and invoice cells.

The independent corpus control for the main candidate retained all 1,662
candidate raster fingerprints and reference fingerprints from its unchanged
parent: 1,625 PASS, 19 FAIL, and 18 REFERENCE-DISPUTED. These pre-existing
failures were not removed by changing fixtures, thresholds, or baselines.
That evidence applies to the main candidate; the stable backport is separately
qualified with its own installed wheel and release checks.

## Stable qualification and release gates

The [first stable source CI](https://github.com/fullbleed-engine/fullbleed-official/actions/runs/42502958236)
passes all 48 new regressions on both Windows and Linux. Its intentionally
unfinished packaged contracts still identify 2.5.51; they are regenerated from
that CI-built 2.5.52 wheel before the final build. The Rust run passes 1,438
tests and exposes a pagination-event fixture whose text now fits on one page.
The fixture is corrected to exercise fixed-height automatic overflow, matching
the existing main-branch test; its page-count and event assertions remain.

The installed Windows candidate also passes all 48 focused cases. The original
Pretendard OTF/TTF examples have identical PDFium bounds, and native previews
agree within one pixel at 144 dpi. The original alignment, OTF, and invoice
examples were visually reviewed. These candidate results do not replace the
final all-pass CI gate.

The installed candidate passes 1,008 Python tests. Four schema tests initially
skip because the local test environment lacks `jsonschema`; all four then pass
with that test-only dependency installed. The final built wheel passes the 48
focused regressions, installed-package smoke, and generated-contract check.
Windows and Linux CI each pass 1,440 Rust tests.

The golden-document review compares the published 2.5.51 wheel with the rebuilt
2.5.52 wheel. The former reproduces every committed PDF and PNG hash; the latter
reproduces the remote CI output. Visual inspection confirms right alignment of
the invoice metadata and bank contact details, and corrected centering and
font measurement in the menu's right panel. Every page retains its text and
the page counts remain 1, 2, and 1. The bank's second page is byte-identical.
Only the three reviewed PDF hashes and three changed PNG baselines are updated;
fixtures, validation contracts, and comparison thresholds remain unchanged.

The stable CI runs all 48 new grid/font/table regression cases on Windows and
Linux and retains their PDFs, previews, and test results. The release workflow
also runs these cases before the full Python suite. Existing Rust/MSRV, golden
document, font subset, table semantics, compiled rendering, and package checks
