# Stable v2.5.50: counters across contents wrappers

## Scope

Generated counters continue through `display: contents` wrappers without adding
a containing-box scope. Their children and pseudo-elements share the surrounding
counter sequence. The document tree remains intact for selectors and inherited
styles. Ordinary containing boxes retain their counter scopes.

The original witness is the pinned Web Platform Tests
[`counter-order-display-contents.html`](https://github.com/web-platform-tests/wpt/blob/bdcdab01d8998ee249e4b8b7adbedc1d4e61638e/css/css-lists/counter-order-display-contents.html).
The public 2.5.49 wheel renders `C=1 One`, `C=1 Two`, `C=1 Three`; Chromium
153.0.8010.12 and the candidate render `C=1 One`, `C=2 Two`, `C=3 Three`.
The healthy physical-container reference PDF is byte-for-byte unchanged.

build. The release gates below remain required.

- The installed candidate passes all 950 Python tests. Native source
  CI: [run 41277451953](https://github.com/fullbleed-engine/fullbleed-official/actions/runs/41277451953).

## Required release qualification

1. Qualify the unchanged full source corpus against the retained baseline:
   compare inputs, references, thresholds, verdicts and saved PDF bytes. Retain
   known failures and disputed references; do not reinterpret a failed all-pass
   gate as conformance. Review any changed result before proceeding.
2. Build and install a versioned 2.5.50 wheel before generating agent artifacts.
   Generate them with `tools/generate_agent_contract.py`; do not hand-edit them.
3. Build the final wheel and check its installed runtime, packaged resources,
   saved PDFs, metadata, licenses and bundled Skill. Preserve all failures and
   skips from final source and release CI.
4. Forward-port the fix into main while keeping component authoring alpha.
   Qualify the resulting source before merging.
5. Publish through the existing trusted workflows and verify fresh public
   distributions before claiming delivery. Keep release evidence with the
   release assets.

## Boundaries

The 2.5.49 contents-pseudo-element discrepancy is resolved by these saved-PDF
checks. The external corpus still has failures and disputed references. These
checks do not establish complete CSS conformance or browser raster parity.
Default HTML list markers and general mutations of implicit list and footnote
numbering retain their existing limitations. This change makes no accessibility,
performance or independent-adoption claim. Components remain alpha.
