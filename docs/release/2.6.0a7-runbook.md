# Component alpha 7 qualification

Python prerelease: `2.6.0a7`, tag `v2.6.0a7`. Cargo source: `2.6.0-alpha.7`.

This preview delivers the caption-ownership correction from issue #98 and a
source showcase that can render and inspect PDF/UA-1 or PDF/UA-2. Keep the
component API experimental and keep stable 2.5.32 as the default installation.

1. Preserve the caption candidate's source and verification evidence: 1,427 Rust
   unit tests, 939 Python tests, 225 caption cases, 180 rich-table cases and 272
   independently validated PDFs. Check exact source hashes before reusing any
   evidence; distinguish candidate results from release results.
2. Synchronize Python, Cargo and CI versions. Build and install the alpha wheel,
   regenerate agent artifacts from that runtime, rebuild the final wheel and
   check contracts, metadata, the bundled Skill and distribution contents.
3. Run focused release/contract tests and the full Python suite on the final
   installed wheel. Exercise both showcase CLI profiles and reject the retained
   duplicate-caption and nested-MCID PDFs with the independent reader.
4. Compare all caption outputs with the qualified candidate. Recreate Northstar
   and Common Ground from both authoring paths. Recreate both accessible guide
   profiles; retain PDF hashes, text/pixel comparisons, structure reports and
   independent validator JSON with empty stderr. Validation may be inherited
   only for a byte-identical saved PDF with a verified receipt and file hash.
5. Require current-source Windows/Linux CI. Preserve the independent CSS
   corpus's existing failures and disputed references. Compare its complete
   verdicts, scores and saved outputs; inspect any changed file. Do not change
   reference images, tolerances or verdicts to obtain a passing workflow.
6. Verify the exact-tag release workflow and all 15 public wheels plus the
   source archive. Use fresh public installations to reproduce the caption
   outputs and both guide profiles before publishing the GitHub prerelease.
7. Publish a versioned source kit and both guide PDFs with their exact receipts.
   Reproduce the downloaded ZIP on Windows and Linux; check the docs, real ZIP
   download and both PDF links in the browser at 1440, 390 and 320 pixels. Keep
   historical kits, PDFs and receipts byte-identical.

The authored guide's machine checks do not establish human assistive-technology
usability, general WCAG certification or conformance for arbitrary documents.
Rich-cell continuation with middle/bottom alignment remains unsupported.
Static Bootstrap exports contain no Bootstrap JavaScript. Dedicated PDF/VT
validation remains unconfigured. Do not introduce browser rendering, system
fonts or optional integrations into the core package.
