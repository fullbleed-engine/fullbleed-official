Python prerelease: `2.6.0a14`; Cargo source: `2.6.0-alpha.14`; tag: `v2.6.0a14`.

This release packages [PR #125](https://github.com/fullbleed-engine/fullbleed-official/pull/125):
authored PDF links, inline opacity, imported-link clipping, table text alignment,
and preview-worker recovery. The component API remains alpha. Independent-kit
integration and retained independent author feedback remain graduation gates.

   tag availability before preparing the new version. Preserve unrelated local

   Build and install the new-version wheel. Generate agent artifacts from that
   installed runtime, rebuild the final wheel, then check the generated contract,
   installed-package behavior, metadata, licenses and bundled versionless Skill.
   Do not hand-edit the contract, CLI schema or `llms.txt`.
3. Run focused links, inline-opacity, imported-link composition, PDF-version,

   installed wheel, followed by the full Python suite. Retain the native suite

   Reproduce the independent reader and imported-border checks. Keep measured

   Investigate any final-version difference before publication.
6. After qualification, create an immutable annotated tag. Require the release

   the workflow output; install the public wheel in a fresh environment and

7. Publish a GitHub prerelease with scoped notes, rendering/corpus evidence and
   hashes. Update the current docs only after verifying the public package,

   it the sole entry point.

Exact curve boundaries, general source-reader pixel parity, keyboard navigation,
assistive-technology behavior and matching mouse-highlight appearance remain
unqualified. Composition does not preserve imported structure trees; stamping
preserves the tested template ownership. Dedicated PDF/VT validation remains
unavailable. These checks do not establish complete CSS, accessibility or profile
conformance, independent adoption, or stable-component graduation.
