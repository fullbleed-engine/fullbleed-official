# Fullbleed 2.5.6 release runbook

This patch removes duplicate searchable text from upright synthesized bold and
keeps its glyph paint reusable. Publish from a clean annotated `v2.5.6` tag after
the checks below pass.

## Build and verify

Keep Cargo, Python, CI smoke metadata, release defaults, and generated agent
artifacts synchronized at 2.5.6. The optional MCP adapter remains 0.1.1 and the
audit crate remains 0.1.3. Historical example pins retain their verified versions.

Build and install a wheel in an isolated environment. Generate agent artifacts
using `tools/generate_agent_contract.py --python PATH --json`, rebuild and install
the final wheel, then run the generator with `--check`. Build the sdist from that
same source. Do not hand-edit generated agent artifacts.

- Run the synthetic-bold PDF writer and finalized-preview Rust tests, then the
  full Rust suite with default and Python/SVG features.
- Run focused installed-native Python extraction, preview, compiled-table, and
  profile tests; then run the full Python suite with
  `FULLBLEED_TEST_INSTALLED_NATIVE=1`.
  Include repeat rendering of fixed, reflow, and compact bindings so glyph
  resources survive cached, multiple-record output.
- Install the test-only reader `pypdf==6.19.0` and run
  `python -I tools/smoke_text_extraction.py --out target/text-extraction`.
  Retain all 36 PDFs, source HTML/CSS, direct/finalized PNGs, text, coverage
  measurements, and hashes. The public 2.5.5 quickstart must fail the single-copy
  check. A candidate that painted oversized strokes was rejected by the visual
  coverage control; do not weaken that check to accept boxes or blank glyphs.
- Extract the same PDFs with PyMuPDF, pdfminer.six, and PDFium. Compare normalized
  text with the authored expected values; retain reader versions and results.
- Compare actual PDFs with public 2.5.5 fixtures using an independent renderer.
  Compare only identical HTML/CSS inputs. Inspect native previews, including
  Unicode, italic, opacity, shadows, rotated, scaled, and sheared bold.
- Verify that previews of retained earlier-version PDFs remain unchanged.
- Review golden changes. The Acme invoice loses its duplicate Type 3 text and
  needs a new PDF hash; its direct PNG baseline stays unchanged. Compare the
  before/after PDFs with an independent renderer before accepting the hash.
- Run installed-package smoke, agent-contract checks, metadata/license checks,
  deterministic goldens, CSS status, and the bundled Skill publishing dry run.
- Require Linux and Windows CI, the full platform-wheel/source-distribution
  release workflow, and the existing print-profile checks.

## Publish and verify

Use the configured PyPI trusted publisher and crates.io workflow. Retain the
source tag, successful CI, public registry metadata, and artifact hashes. Install
the public wheel in a fresh environment and repeat the styled extraction check.
Update the optional Node package to the published engine, verify the packed npm
tarball, and repeat the original Node invoice reproduction before promoting it.

These checks establish behavior for the retained fixtures. They do not establish
general PDF renderer parity, screen-reader acceptance, or profile conformance.
The dedicated PDF/VT validator remains unconfigured; its skipped check does not
establish independent conformance. PDF/PNG hashes can change for affected output.
