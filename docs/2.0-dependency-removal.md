# FullBleed 2.0 Dependency Removal

Status: implementation complete; publication automation pending

## Completion contract

The 2.0 dependency-removal work is complete when:

- the Rust engine's normal and optional feature graphs contain only FullBleed-authored crates;
- the standalone `fullbleed_audit_contract` crate has no third-party graph;
- Python runtime, optional API support, and the PEP 517 build path require no third-party Python
  packages;
- current Rust/Python behavior, public capabilities, deterministic output, supported file formats,
  and platform matrix remain covered by release gates;
- manifests, lockfiles, release metadata, licensing records, and documentation describe the 2.0
  graph accurately.

Bundled fonts, CSS, and icon artwork are redistributed assets rather than linked software
dependencies. They remain governed by `THIRD_PARTY_LICENSES.md` and the font-license audit; this
project does not silently relicense those works as FullBleed code.

The independently publishable audit-contract lockfile now contains exactly its own package.

The native font boundary is shared by PDF embedding, layout measurement, shaping, and rasterization.
Its generated Unicode 14 tables pin and verify the Unicode Consortium Arabic-shaping and
bidirectional-mirroring inputs by SHA-256. Removing the former font stack also removed its Unicode
helper crates from both normal and optional Cargo graphs.

## Remaining direct graph

None. The root package depends only on the FullBleed-authored `fullbleed_audit_contract` path
crate, and that crate has no dependencies of its own. Optional features add no packages.

## Verification gates

The completed local baseline is:

```powershell
cargo fmt --all --check
cargo test --locked
cargo test --locked --features python,svg_raster
cargo tree -e normal --depth 1
cargo tree -e normal --depth 1 --all-features
python -m pytest -q
```

The packaged Rust 1.85 consumer, both Cargo publish dry runs, dependency-free Python build/install
smoke, license and metadata checks, checked CSS parity ledger, and byte-identical checkout/sdist
wheel gate pass for the release candidate. The final wheel's Windows extension imports only
`python3.dll`, and the source distribution contains no generated native extension. The 658-test
Rust suites each report 657 passed and one explicit local-font opt-in ignored; the exact wheel
passes all 248 Python tests. The 15-platform wheel matrix and clean-tag/worktree check remain
publication-automation gates.
